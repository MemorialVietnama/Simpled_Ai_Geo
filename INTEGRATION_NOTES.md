# Интеграция сцены сравнения моделей (ComparisonScene)

## Обзор изменений

Была интегрирована сцена `ComparisonScene` для отображения результатов упрощения модели.

## Изменения в файлах

### 1. scenemanager.h
- Добавлен include для `comparisonscene.h`
- Добавлен метод `goToComparison()`
- Добавлен геттер `getComparisonScene()`
- Добавлены слоты:
  - `onComparisonRequested()`
  - `onComparisonBackRequested()`
  - `onSaveRequested()`
- Добавлены поля для хранения данных:
  - `ComparisonScene *comparisonScene`
  - `QJsonObject originalModelData`
  - `QJsonObject simplifiedModelData`
  - `QJsonObject simplificationResult`

### 2. scenemanager.cpp
- Инициализация `ComparisonScene` в конструкторе
- Добавление сцены в `stackedWidget`
- Подключение сигналов от `SimplifyScene` и `ComparisonScene`
- Реализация методов:
  - `goToComparison()` - переход к сцене сравнения
  - `onComparisonRequested()` - обработка запроса на сравнение
  - `onComparisonBackRequested()` - возврат к сцене упрощения
  - `onSaveRequested()` - сохранение упрощенной модели
- Обновлен `goToSimplify()` для передачи данных модели

### 3. simplifyscene.h
- Добавлен метод `generateNeuralNetworkFromModel()`

### 4. simplifyscene.cpp
- Добавлена реализация `generateNeuralNetworkFromModel()` для генерации визуализации на основе данных модели
- Обновлен `setModelData()` для автоматической генерации визуализации

### 5. comparisonscene.cpp
- Добавлен вызов `setupConnections()` в конструкторе

## Поток работы приложения

```
1. FileSelectionScene (выбор файла)
   ↓
2. LoaderScene (загрузка)
   ↓
3. AnalysisScene (анализ модели)
   ↓
4. SimplifyScene (упрощение модели)
   ↓
5. ComparisonScene (сравнение оригинала и упрощенной модели)
```

## Возможности ComparisonScene

### Вкладки:
1. **Текстовое сравнение** - таблица с сравнением параметров
2. **3D Сравнение** - визуальное сравнение структуры моделей
3. **Статистика** - графики и диаграммы

### Отображаемые метрики:
- Общее количество параметров
- Размер файла (MB)
- Количество слоев
- Количество нейронов
- Количество связей
- Коэффициент сжатия
- Сокращение размера (%)
- Потеря точности (%)

### Функциональность:
- Кнопка "Назад" для возврата к сцене упрощения
- Кнопка "Сохранить" для сохранения упрощенной модели
- Интерактивная 3D визуализация с возможностью вращения и масштабирования
- Настройка прозрачности для наложения моделей
- Режимы отображения: "бок о бок" или "наложение"

## Тестирование

Для тестирования:
1. Запустите приложение
2. Выберите файл модели
3. Дождитесь завершения анализа
4. Нажмите "Упростить модель"
5. После завершения упрощения нажмите "Сравнить модели"
6. Просмотрите результаты в разных вкладках
